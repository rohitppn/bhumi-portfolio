# Bhumi Socials — Portfolio

Personal portfolio site for **Bhumi**, a Social Media Manager & Content Strategist with 5+ years of experience.

🔗 **Live site:** https://rohitppn.github.io/bhumi-portfolio/

## Stack

Pure static — no build step.

- `index.html` — semantic markup, single page with smooth-scroll sections
- `styles.css` — pink / magenta / cream palette, Playfair Display + Pinyon Script + Anton + Inter
- `script.js` — custom cursor, scroll progress, reveal-on-scroll, counter animations, magnetic CTAs, 3D tilt, mobile menu
- `assets/img/` — photos and real Instagram + WhatsApp screenshots

## Sections

1. Hero with animated letter-drop title
2. About + tools used
3. Services (7 social platforms + 4 other services)
4. Why Work With Me
5. Skills (technical + soft)
6. Content I Create (folder tiles)
7. **Projects** — 5 case studies with real Instagram screenshots
8. **Reviews** — featured real WhatsApp screenshot + testimonials
9. Contact (email, phone, WhatsApp links all working)

## Run locally

Just open `index.html` in a browser — or:

```bash
npx serve .
```

## Deploy

Drop the folder into Netlify / Vercel / GitHub Pages — it's a static site, no config needed.
